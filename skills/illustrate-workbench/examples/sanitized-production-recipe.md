# Sanitized recipe derived from a prior successful run

This preserves the method and visual instructions of an actual prior workflow while replacing project-specific content. It is not the verbatim private prompt and does not include its source screenshots. The neutral substitutions below have not themselves been rendered as a test.

## Reference map used by that workflow

1. Approved assistant identity image
2. Genuine draft application screen A
3. Genuine draft application screen B
4. Separate verified project logo

No canonical location image was used in that run. Its consistent character came from the supplied likeness; the environment was described in the prompt. Explicit location packs in this package add a repeatability mechanism that needs its own validation.

## What this supports

These patterns demonstrate the origin of the prompt workflow and the importance of inspecting actual outputs. They do not establish perfect logo reproduction, source-pixel fidelity, persistent room consistency, cross-platform installation, or deterministic repeatability. Current public showcase tests are reported separately in `validation-log.md`.
